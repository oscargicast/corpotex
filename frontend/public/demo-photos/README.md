# Fotos de ejemplo del simulador

Copias de `backend/seed/images/products/` (data de demo, ADR 0021: bancos libres de derechos o generadas, nunca fotos reales de Corpotex). Las fuentes y créditos están junto al seed. `manifest.json` lista las que ofrece el botón "Fotos de ejemplo" del simulador; sin archivos en la lista, el botón no aparece.
